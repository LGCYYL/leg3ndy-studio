# LEG3NDY Studio v1.3.2 - Compatibilidade e Ajustes do macOS

A **v1.3.2** traz correções importantes para permitir que o aplicativo seja executado corretamente no macOS como um projeto open-source e não assinado.

## Correções e Melhorias

### ✅ Correção do erro de app danificado no macOS
- **Problema:** Ao baixar o aplicativo no macOS, ele era acusado de estar "danificado" e o Gatekeeper impedia a abertura, pois o build tentava aplicar regras de segurança (entitlements e hardened runtime) sem possuir uma assinatura oficial da Apple Developer.
- **Correção:** Simplificamos o empacotamento do macOS removendo as configurações de segurança que exigem assinatura paga da Apple, tornando o build compatível com distribuição aberta e não assinada (onde o usuário pode usar o comando de bypass `xattr`).

### ✅ Correção de permissão negada nos binários internos do macOS
- **Problema:** Quando os binários do Node.js, FFmpeg e da Engine Python eram copiados para dentro do pacote do macOS, eles perdiam a permissão de execução (`chmod +x`), gerando falhas ao iniciar o download ou a análise de vídeos.
- **Correção:** Ajustamos o script de preparação para aplicar a permissão `chmod 755` automaticamente nestes binários durante o empacotamento, garantindo que o Electron consiga iniciar e gerenciar os serviços internos de forma transparente.
