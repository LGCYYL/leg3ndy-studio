# LEG3NDY Studio v1.3.0 - Nova Base Premium e Expansão de Plataforma

A **v1.3.0** marca o início oficial da nova fase do **LEG3NDY Studio**. Esta versão não só reorganiza a base do projeto e moderniza a arquitetura, como também já corrige fluxos críticos de mídia e prepara o app para crescer além do Windows com uma estrutura muito mais sólida.

---

## 🌟 O que faz do LEG3NDY Studio a experiência premium?

Para quem está chegando agora, aqui está o que define a proposta atual do projeto:

- **⚛️ Arquitetura moderna com React + TypeScript:** a interface agora vive sobre uma base mais organizada, previsível e escalável, deixando para trás a dependência de uma estrutura centrada em HTML/script como fonte principal da UI.
- **🖥️ App desktop real com Electron:** janela customizada, bridge segura, integração com sistema operacional, auto-start, tray e empacotamento mais consistente.
- **🚀 Engine multi-source:** análise de conteúdo, fila, preview, biblioteca e fluxo de download integrados em uma experiência única de desktop.
- **🗂️ Gestão local de biblioteca:** os arquivos baixados continuam acessíveis de forma prática dentro do app, com visual consistente e foco em produtividade.
- **🎨 Identidade visual mais sólida:** branding, header, sidebar, assets e ícones agora seguem uma direção muito mais coesa para a evolução futura do produto.

---

## 🆕 Novidades da v1.3.0

### ✅ Migração da interface para React + TypeScript
- **Problema/Motivação:** a base anterior era mais difícil de evoluir e manter conforme a interface crescia.
- **Solução:** a UI foi reorganizada em componentes React com tipagem TypeScript, criando uma base mais profissional para futuras features e refinamentos.

### ✅ Nova arquitetura de renderer com Vite
- **Problema/Motivação:** o fluxo antigo de frontend e build dificultava manutenção e expansão do app.
- **Solução:** adotamos uma estrutura moderna com **Vite + TypeScript**, separando melhor renderer, Electron e assets do projeto.

### ✅ Padronização de assets e ícones do app
- **Problema/Motivação:** imagens e ícones estavam dispersos, o que dificultava consistência visual e manutenção.
- **Solução:** os assets foram centralizados em `public`, e o app passou a gerar ícones desktop padronizados (`.ico`, `.icns` e `.png`) a partir da identidade visual atual.

### ✅ Refinos de fidelidade visual e branding
- **Problema/Motivação:** durante a modernização da base, algumas partes da interface perderam fidelidade em relação ao visual desejado.
- **Solução:** sidebar, brand, header superior, placeholders da biblioteca e detalhes de layout foram ajustados para recuperar consistência e elevar a sensação premium do produto.

### ✅ Correção crítica de formatos em vídeos mais restritos do YouTube
- **Problema/Motivação:** alguns vídeos, especialmente casos como trailers, filmes e canais no estilo Movieclips, apareciam só com qualidades baixas mesmo quando havia resoluções superiores disponíveis.
- **Solução:** a engine foi fortalecida com atualização de `yt-dlp`, melhor estratégia de fallbacks, seleção mais inteligente de formatos e uso correto de `format_id` no download.

### ✅ Prévia de mídia com qualidade muito melhor
- **Problema/Motivação:** a prévia estava presa em qualidade baixa e, em alguns casos, nem carregava direito para conteúdos mais sensíveis.
- **Solução:** o fluxo de preview passou a escolher a melhor fonte disponível por padrão, com suporte melhorado a fontes modernas e fallback mais robusto no player.

### ✅ Base inicial de compatibilidade com macOS
- **Problema/Motivação:** o app estava fortemente acoplado a caminhos, binários e fluxo de empacotamento específicos do Windows.
- **Solução:** a base agora já trata diretórios de app data por plataforma, descoberta cross-platform de binários, empacotamento para `dmg/zip`, barra nativa no mac, entitlements e hook de notarização.

## 🛠️ Ajustes Técnicos / Menores

- Remoção de elementos visuais intrusivos, como o toast superior que não fazia parte da experiência desejada.
- Separação do `AppUserModelID` no modo desenvolvimento para evitar conflito visual de ícone no Windows durante `npm start`.
- Geração automatizada de ícones no processo de build.
- Bridge do Electron expandida para expor informações de runtime ao renderer quando necessário.
- Scripts de release preparados para empacotar runtime, `ffmpeg`, `node` e recursos auxiliares com mais consistência.
- Workflow de CI ajustado para preparar releases de Windows e macOS.
- Estrutura de documentação de release iniciada oficialmente dentro do projeto.

---

## 🎨 UX / Visual

- Sidebar com lockup mais forte da marca, usando o ícone oficial do app.
- Header desktop superior refinado e mais alinhado com o padrão visual dos outros apps do ecossistema LEG3NDY.
- Biblioteca com placeholders ajustados para manter o mesmo footprint das thumbs reais.
- Prévia de mídia e resultado de análise mais consistentes visualmente.
- No macOS, a aplicação já está preparada para usar uma experiência de janela mais nativa.

## 🍎 Nota Sobre macOS

A **v1.3.0** já deixa o projeto tecnicamente muito mais perto da paridade de plataforma, mas o fechamento completo do fluxo macOS ainda depende de validação final em um Mac real, assinatura Apple e notarização em ambiente de release.

Mesmo assim, a fundação necessária para isso já entrou nesta versão.
