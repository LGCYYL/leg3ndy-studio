# LEG3NDY Studio v1.3.1 - Correções Visuais de Boot

A **v1.3.1** é uma atualização focada em estabilidade visual e consistência no carregamento inicial da interface.

## Correções

### ✅ Versão do sistema agora aparece corretamente
- **Problema:** em alguns cenários o card de versão podia ficar preso em `?.?.?` logo após abrir o app.
- **Correção:** o carregamento da versão do app foi desacoplado do boot do backend, evitando que uma falha temporária da API interna esconda a versão real.

### ✅ Card da pasta salva não cai mais em `Padrão` indevidamente
- **Problema:** a sidebar podia mostrar `Padrão` mesmo com uma pasta personalizada já salva.
- **Correção:** o carregamento inicial do config ficou mais resiliente, com retry no boot e fallback visual usando o caminho ativo salvo.

### ✅ Boot visual mais robusto
- **Problema:** pequenas corridas de inicialização entre Electron e backend deixavam partes da UI em estado de fallback visual.
- **Correção:** o bootstrap inicial foi reorganizado para carregar dados do shell separadamente e retryar apenas o que depende do backend.
